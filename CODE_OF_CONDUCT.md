# Code of Conduct

Nova is intended to be a welcoming project for beginners and experienced
developers alike.

Participants are expected to:

- be respectful and constructive;
- assume good faith;
- explain disagreements with technical reasoning;
- welcome questions from beginners;
- avoid harassment, personal attacks, discrimination, and intimidation.

Project maintainers may remove comments, issues, pull requests, or other
participation that violates this standard.
