# Nova Roadmap

The roadmap prioritizes reliability and usability before adding language
complexity.

## 0.x / early public releases

- Stabilize the language semantics.
- Expand the conformance test suite.
- Improve diagnostics.
- Improve the CLI and REPL.
- Publish the browser playground.

## Next platform layer

- Modules and imports.
- File system APIs.
- JSON support.
- HTTP and networking APIs.
- Process and environment APIs.
- More complete standard library.

## Developer ecosystem

- Package manager.
- Project manifest (`nova.toml`).
- Formatter.
- Test runner.
- VS Code extension.
- Language Server Protocol support.
- Debugger.

## Application platform

- Database libraries.
- Web framework.
- Async/concurrency model.
- Desktop/UI integration.
- Native extension interface.

## Performance

Once language semantics are stable, evaluate a bytecode compiler and Nova VM
rather than prematurely complicating the language syntax.
