# Nova v2.0.1 Runtime Hardening

Nova v2.0.1 is a hardening release focused on keeping the language beginner-friendly while making the runtime safer and more predictable.

## Implemented in the packaged build

- Real SQLite database handles from `db_open()` with backward-compatible string paths.
- SQL identifier validation for table and column names.
- Clearer SQLite dependency errors.
- Safer synchronous HTTP client invocation without shell interpolation.
- HTTP URL validation, timeouts and response-size limits.
- HTTP server request-size protection and `http_stop()`.
- HTML escaping by default in GUI builders, with explicit `gui_raw()` for trusted HTML.
- GUI value validation for grid columns, badge styles and alert types.
- `--safe` runtime mode disables filesystem, database, network and GUI capabilities.
- Correct short-circuit `or` evaluation.
- Descending ranges and zero-step validation.
- Clearer missing/extra/unexpected function argument errors.
- Improved CLI: `run`, `check`, `repl`, `--safe`, `--version` and help commands.
- Removed the unused `node-fetch` dependency.
- Added a 15-test regression suite including a real local HTTP server test.
