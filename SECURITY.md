# Security Policy

## Supported versions

Security fixes are provided for the latest supported Nova release.

## Reporting a vulnerability

Please do not disclose a suspected security vulnerability in a public issue.

Until a dedicated security contact is published, open a private security
report through GitHub's repository security features if they are enabled.
If private reporting is unavailable, contact the project maintainers before
publishing details publicly.

When reporting an issue, include:

- Nova version
- operating system
- minimal reproduction
- expected behavior
- actual behavior
- any relevant stack trace or input file

Please avoid including passwords, API keys, personal information, or other
secrets in reports.
